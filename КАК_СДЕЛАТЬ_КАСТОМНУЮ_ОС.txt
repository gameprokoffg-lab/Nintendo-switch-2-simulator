КАК СДЕЛАТЬ КАСТОМНУЮ ОС ДЛЯ СИМУЛЯТОРА NINTENDO SWITCH 2
================================================================

Что это
-------
Прошивка (кастомная ОС) — обычный текстовый файл .js, который описывает
системный блок консоли: название, акцентный цвет, обои, автозапуск игр
и дополнительные настройки. Симулятор читает этот файл, применяет его
к интерфейсу и считает, сколько места прошивка занимает в памяти.

Готовая заготовка лежит рядом: КАСТОМНАЯ_ОС_ШАБЛОН.js
Её можно скопировать, изменить значения и загрузить.

Быстрый старт
-------------
1. Создайте аккаунт Nintendo при первом включении консоли.
2. Настройки -> Разблокировать загрузчик. Введите пароль аккаунта.
3. В Настройках появится пункт «Поставить кастомную ОС» — откроется
   терминал с зелёной надписью INSERT CARD.
4. Откройте Game Loader, перетащите туда свой .js с прошивкой и
   поставьте галочку «Это кастомная ОС (прошивка)». На столе появится
   фиолетовый картридж прошивки.
5. Вставьте этот картридж в консоль, пока открыт терминал INSERT CARD.
   Терминал прошьёт ОС: название, обои и настройки сменятся.

Формат файла
------------
Файл — это JavaScript. Внутри обязателен объект SwitchFirmware:

var SwitchFirmware = {
  name: "Моя кастомная ОС",     // имя прошивки
  version: "1.0",               // версия
  accent: "#ff9f4a",            // акцентный цвет интерфейса
  homeTitle: "MY OS",           // заголовок главного экрана
  autoRun: false,               // true — картридж запускается сам
  wallpaper: "radial-gradient(...)",  // фон главного экрана (CSS)
  settings: [ ... ]             // свои настройки (необязательно)
};

Комментарии-метаданные (необязательно):
//#name: Моя кастомная ОС
//#version: 1.0
//#accent: #ff9f4a

Они нужны, если объект не задан или имя нужно взять из шапки.

Вес и память
------------
Вес прошивки считается по строкам: 1 строка = 100 МБ.
Файл на 18 строк занимает 1.8 ГБ. Заводская прошивка — отдельный файл
js/firmware-default.js, её вес тоже вычитается из памяти.

Всего в консоли 256 ГБ. Формула свободного места:
256 ГБ − вес прошивки − вес установленных игр.

Если прошивка не помещается, терминал напишет
«not enough space» и установка не начнётся.
Где смотреть: Настройки -> Память.

Свои настройки
--------------
Массив settings добавляет пункты в Настройки:

settings: [
  { key: "autoRun", label: "Автозапуск картриджа", type: "bool" },
  { key: "owner",   label: "Имя сборки",           type: "text", value: "my-os" }
]

type: "bool" — переключатель вкл/выкл.
type: "text" — строка, вводится в окне.
Значения сохраняются на консоли и переживают перезагрузку страницы.

Что реально меняется в симуляторе:
- accent      — цвет акцента (кнопки eShop, полоска под заголовком);
- wallpaper   — фон главного экрана (любой CSS background);
- name/version — отображаются в Настройках -> Система;
- autoRun     — вставленный картридж сам запускает игру;
- settings    — дополнительные пункты в Настройках.

Как установить
--------------
1. Настройки -> Разблокировать загрузчик (пароль аккаунта).
2. Настройки -> Поставить кастомную ОС.
3. В терминале появится INSERT CARD.
4. Вставьте картридж прошивки в слот консоли.
5. Терминал покажет чтение, проверку подписи и прошивку блоков,
   затем консоль перезагрузится с новой ОС.

Вернуть заводскую прошивку: Настройки -> Вернуть заводскую прошивку.

Карта «Обычная прошивка»
------------------------
В комнате-хранилище первый слот занят картой «Обычная прошивка».
Если вставить её в терминале INSERT CARD, консоль сбросится до
заводских настроек: удалятся профиль, игры и кастомная ОС. Это
работает даже из экрана INSERT CARD — карта специально для сброса.

Сброс до заводских также есть в Настройках.

Публикация в eShop
------------------
1. Загрузите прошивку через Game Loader (галочка «кастомная ОС»).
2. Вставьте картридж прошивки в консоль.
3. Откройте eShop -> «Выложить».
4. Укажите название, описание и картинку, раздел «Кастомная ОС».
5. Другие аккаунты увидят прошивку в eShop и смогут скачать её
   как картридж, чтобы установить у себя.

Аккаунты и публикации хранятся в отдельном файле сети: кнопки
«Сохранить файл сети» / «Загрузить файл» внизу eShop. При обновлении
страницы данные сохраняются в localStorage браузера.

Ограничения
-----------
- Прошивка — это код, он выполняется локально. Не загружайте чужие
  файлы, которым не доверяете.
- Сеть в симуляторе имитируется файлом: реальных запросов нет.
- Картинки обоев задаются CSS; data-URL тоже работает.
- Пароль аккаунта хранится в виде простого хеша — это демонстрация,
  а не защищённое хранилище.

Пример полной прошивки
----------------------
//#name: Neon OS
//#version: 1.0
//#accent: #b06bff
var SwitchFirmware = {
  name: "Neon OS",
  version: "1.0",
  accent: "#b06bff",
  homeTitle: "NEON OS",
  autoRun: true,
  wallpaper: "radial-gradient(120% 100% at 20% 0%, #2a1245 0%, #0b0e13 62%)",
  settings: [
    { key: "autoRun", label: "Автозапуск картриджа", type: "bool" },
    { key: "rgb", label: "RGB-подсветка меню", type: "bool" }
  ]
};

Такую же прошивку можно найти в eShop: раздел «Кастомная ОС»,
публикация Neon OS от IndieDev.

Готовая прошивка NEBULA OS
--------------------------
В папке проекта лежит NEBULA_OS.js — рабочая кастомная прошивка.
Она включает ядро Nebula Runtime (features: ["nebula"]), поэтому
после установки открываются игры «СЕРДЦЕ НЕБУЛЫ» (формат NBS)
и «КРАСНЫЙ СЕКТОР» (формат SEC).

Как поставить:
1. Настройки -> Разблокировать загрузчик (пароль аккаунта).
2. Game Loader -> перетащите NEBULA_OS.js -> отметьте
   «Это кастомная ОС (прошивка)» -> Добавить картридж.
3. Настройки -> Поставить кастомную ОС (терминал INSERT CARD).
4. Вставьте фиолетовый картридж NEBULA OS в слот консоли.

Вес прошивки — 4 ГБ (40 строк). Память: 256 ГБ минус прошивка
и установленные игры. Вернуть заводскую: Настройки -> Вернуть
заводскую прошивку (или карта «Обычная прошивка» в терминале).
